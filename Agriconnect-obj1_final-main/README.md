# AgriConnect+

AgriConnect+ is a farmer decision-support system for comparing crop farming income
against land leasing income. It combines:

- crop price prediction,
- crop yield estimation,
- a farm-vs-lease decision model,
- a deterministic economic engine, and
- an interactive Streamlit dashboard.

## Project Structure

- `dashboard.py` - full Streamlit dashboard.
- `ml_engine.py` - shared inference and economic calculation helpers.
- `train_models.py` - reproducible model training pipeline.
- `crop_prices.csv` - mandi/crop price dataset.
- `crop_yield.csv` - crop yield dataset.
- `lease_rates.json` - state-level lease rates.
- `district_lease_rates.json` - district-level lease rates.
- `models/` - trained model artifacts and paper-ready metrics.

## Setup

```bash
pip install -r requirements.txt
```

## Train Models

```bash
python train_models.py
```

This creates:

- `models/price_model.joblib`
- `models/yield_model.joblib`
- `models/decision_model.joblib`
- `models/metrics.json`

The trained model files are small enough to keep in GitHub. If you retrain,
commit the updated `models/*.joblib` files and `models/metrics.json` together.
The dashboard still runs if the models are missing; it falls back to dataset
lookup and deterministic formulas, and reports the source of each value in the UI.

## Run Dashboard

```bash
streamlit run dashboard.py
```

## Notes for Publication

The decision classifier is trained from labels generated by the economic formula.
For a research paper, describe it as a decision-consistency model unless you add
real farmer outcome/preference labels. The strongest scientific contribution is
the explainable decision pipeline plus price/yield estimation and scenario
analysis.
